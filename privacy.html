Privacy Policy — Phish Check

Last updated: 2026-10-01 · applies to Phish Check version 4.0.0

Phish Check is a browser extension that warns you when the page you are viewing looks like a phishing page. This policy says exactly what it does with your data. It was written from the extension's source code and is checked against it (store/PERMISSIONS.md lists where in the code each point is implemented).

The short version

  • Everything runs on your device. The address of each page and the structure of each page are analysed by models bundled inside the extension. They are never uploaded.
  • By default the extension sends nothing to anyone — not to the developer, not to any server, not to analytics. It has no account, no advertising, no tracking and no telemetry.
  • One optional feature contacts third parties (domain-age lookup). It is off until you switch it on, and your browser asks permission at that moment.
  • Feedback you give is stored on your device only. You can read, delete or export it. It is never sent automatically.

Reports are never uploaded. If you want to help improve the model you can export them as a JSON file (Settings → Your reports → Export) and send that file to the developer yourself; each report is then reviewed by a person and is never used as a training label automatically.

The optional online lookup (off by default)

If, and only if, you switch on Settings → Online lookups, your browser asks for permission to contact two public services, and for each page you visit the domain name only (for example example.com — never the full address, path, query, or page content) is sent to:

  • rdap.org — a public RDAP bootstrap service that returns a domain's registration date;
  • crt.sh — a public certificate-transparency search run by Sectigo, which returns when certificates for that domain were first issued.

These services receive the domain name together with the usual technical information every web request carries (your IP address and browser identification) and are governed by their own privacy policies. The developer receives nothing. Switching the option off removes the permission again. Domains on shared-hosting platforms (for example github.io, web.app) are never looked up. The lookups add little accuracy (measured: about +0.1 percentage points), which is why they are off by default.

What the extension does not do

It does not collect or sell personal data, build a browsing history, use cookies, track you across sites, show ads, load remote code, or phone home. The only network traffic the extension itself ever generates is the optional lookup above.

Permissions

storage, offscreen, and a content script on http/https pages, plus the optional access to rdap.org and crt.sh. Each is explained in store/PERMISSIONS.md. The extension asks for no access to your history, bookmarks, cookies, downloads or the list of your tabs.

Security

All code and models are inside the package; the extension loads no remote scripts. The warning banner is drawn inside a closed shadow root with textContent only, so a web page cannot restyle or read it.

Limits you should know about

Phish Check is an aid, not a guarantee. It can miss phishing pages and can flag legitimate pages. Do not rely on it as your only protection.

Children

The extension is not directed to children and does not knowingly collect any personal data from anyone.

Changes

If a future version changes what data is handled, this policy will be updated before that version is published, and the date at the top will change.
